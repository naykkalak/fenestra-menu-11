# Changelog

## 2.0

### Added
- **Hibernate** button in the power menu, between Sleep and Shut down. It only appears if your computer supports hibernation. Hibernating can fail (the computer may not wake up properly, a faulty disk or too little swap space can lose your session): make sure your system is set up for it before relying on it.
- Choose which buttons appear in the power menu, including Lock, in the menu settings.
- Refresh button in the KDE Connect panel: its icon turns for 2 seconds after a click.
- Search reworked: clearer result rows and highlight, a back arrow to return to the first page, a Settings button next to the filters that opens the KDE search settings, and web search as the last line of the results (it can be collapsed), using the engine chosen in KDE settings. Without any local result, the menu goes straight to the web search.
- A notification tells you in which category a newly installed application was filed, and the "New" badge appears on its tile.
- Default avatar for accounts without a picture.

### Changed
- The menu window keeps a fixed size, according to the number of icons displayed.
- Windows 11 style scroll bar: a thin line while the mouse moves, the full bar on hover.
- Phone battery indicator turned upright in the KDE Connect panel, for easier reading.
- The "···" button of the KDE Connect panel is smaller, the same size as in Fenestra Search.
- The Alt+1–9 hint is no longer shown (the shortcut still works).
- The "···" menu of the KDE Connect panel no longer has "KDE Connect settings": KDE removed that System Settings page. The settings are in the KDE Connect app ("Open KDE Connect").

### Fixed
- Scrolling with the mouse wheel in the menu.
- The built-in icons (phone battery, KDE Connect button, mute) could be replaced by the icon theme.
